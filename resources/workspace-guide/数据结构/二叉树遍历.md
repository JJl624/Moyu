# 二叉树遍历

遍历要让每个节点恰好被访问一次。下面用同一棵二叉树比较四种顺序：根节点是 A，左右孩子是 B、C；B 的孩子是 D、E，C 的孩子是 F、G。

紫色节点表示当前处理的位置，绿色节点表示已经访问。递归经过的边也会变色；下方分别显示递归栈或队列、访问序列，以及当前执行的步骤。可以播放，也可以逐步前进、后退。

## 1. 前序：根 → 左 → 右

```html {id=0010 preview=pin previewHeight=360}
src="./二叉树遍历.assets/attachments/tree/preorder.html"
```

先访问根，再完整遍历左子树，最后遍历右子树。进入 A 就先输出 A；进入 B 后先输出 B，再走到 D、E。左侧全部处理完才轮到 C。

本例结果为 **A B D E C F G**。前序适合先处理父节点、再处理子节点的任务，例如复制树结构。

## 2. 中序：左 → 根 → 右

```html {id=0011 preview=pin previewHeight=360}
src="./二叉树遍历.assets/attachments/tree/inorder.html"
```

先走到底部的左子树，返回时访问根，再处理右子树。虽然最先进入 A，A 却要等 B 的整棵子树结束后才输出。

本例结果为 **D B E A F C G**。二叉搜索树的中序结果按键值有序；这里的字母用于标识节点，这棵示例树并不是二叉搜索树。

## 3. 后序：左 → 右 → 根

```html {id=0012 preview=pin previewHeight=360}
src="./二叉树遍历.assets/attachments/tree/postorder.html"
```

等左右子树都处理完才访问根。D、E 先完成，再输出 B；F、G 完成后输出 C；A 最后输出。

本例结果为 **D E B F G C A**。后序适合必须先得到子树结果的任务，例如计算表达式树、汇总子树大小。

## 4. 层序：逐层，从左到右

```html {id=0013 preview=pin previewHeight=360}
src="./二叉树遍历.assets/attachments/tree/levelorder.html"
```

把根放入队列。每次取出队首并访问，再依次让它的左、右孩子入队。队列前面的节点先处理，因此上一层会先于下一层完成。

本例结果为 **A B C D E F G**。留意队列如何由 A 变成 B、C，再逐步变成 D、E、F、G。

## 比较

| 方法 | 何时访问根 | 本例结果 | 辅助空间 |
| --- | --- | --- | --- |
| 前序 | 左右子树之前 | A B D E C F G | 递归栈 O(h) |
| 中序 | 左右子树之间 | D B E A F C G | 递归栈 O(h) |
| 后序 | 左右子树之后 | D E B F G C A | 递归栈 O(h) |
| 层序 | 按所在层次 | A B C D E F G | 队列 O(w) |

n 是节点数，h 是树高，w 是最大层宽。四种遍历的时间都是 O(n)；递归遇到空子树时直接返回。
