# HTML 小窗口

HTML 代码块可以直接预览交互页面，电脑和手机使用同一套写法。手机无需安装代码运行环境。

## 直接写 HTML

```html
<button onclick="this.textContent = '已访问根节点 A'">访问根节点</button>
```

点击代码块的“预览”操作按钮。钉住后，重新打开文档会直接显示页面；“源码／预览”在同一位置切换。

## 引用本地文件

在 HTML 代码块中单独写一行文件引用：

```html
src="../数据结构/二叉树遍历.assets/attachments/tree/preorder.html"
```

路径相对于当前 Markdown 文档。HTML 文件里的本地 CSS、JavaScript 和图片则相对于该 HTML 文件。完整示例见[二叉树遍历](../数据结构/二叉树遍历.md)：前序、中序、后序和层序分别有一个动画，支持播放、暂停、单步和重置。

普通附件链接只作为链接显示；把 HTML 文件路径放进 HTML 代码块才会得到内嵌页面。

## 大小、保存与同步

拖动预览窗口底边调整高度。手机上先长按底边，再拖动；双击恢复默认高度。窗口宽度跟随页面，适合手机和电脑的不同屏幕。

钉住状态和高度保存在代码块属性中，例如 `{preview=pin previewHeight=238}`。这些属性会随 Markdown 一起保存和同步；手动保存模式下需要点击保存。引用的 HTML、CSS、脚本和图片也需要随知识库一起同步。

钉住保留的是源代码或文件引用，以及显示高度。动画进度、按钮点击次数等页面内存状态会在刷新或重新打开时重置。页面只加载知识库内明确引用的文件；预览不加载远程脚本、联网请求或嵌套网页。

## 电脑已有的 HTML 运行结果

电脑上钉住的 HTML 运行结果同步到手机后也可查看和调整高度，不需要在手机重新运行代码。该结果使用原有结果文件和尺寸记录；取消钉住会移除保存的结果。
