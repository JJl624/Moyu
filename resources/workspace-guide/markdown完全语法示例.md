# markdown完全语法示例

本页演示 Markdown、GFM 和 Moyu 的编辑操作。可以直接修改示例，对照“源码”与“阅读”查看保存的文字和渲染结果。

代码运行与文件读写见[公式和代码示例](公式和代码示例.md)，图表语法见[mermaid绘图大全](mermaid绘图大全.md)。

## 1. 编辑模式与光标

| 模式 | 用途 |
| --- | --- |
| 预览编辑 | 编辑文字并查看样式，光标靠近时显示对应 Markdown 标记 |
| 源码 | 直接编辑完整 Markdown |
| 阅读 | 只读查看渲染结果 |

切换文档或模式会保留编辑位置。行内代码、强调、公式和链接在光标靠近时显示标记；空格、方向键和删除键按文字处理。

在可插入的位置输入 `/` 可打开代码块、表格和绘图菜单。选中文字后会出现常用编辑工具；常驻格式工具栏可在“偏好设置 → 编辑”中开关。

## 2. 标题、段落与换行

```markdown {id=0001}
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

在 `#` 后输入空格创建标题，最多六级。光标进入标题时显示 `#` 标记，右侧“大纲”可定位标题。

段落之间留一个空行。Enter 新建段落，Shift + Enter 在段内换行。

这是第一段。

这是第二段。下面两句属于同一段：
第一行  
第二行

## 3. 文字格式

**加粗**、*斜体*、***加粗斜体***、~~删除线~~、==高亮==、__下划线__、行内代码 `const value = 1`。

```markdown {id=0002}
**加粗**
*斜体*
***加粗斜体***
~~删除线~~
==高亮==
__下划线__
__**加粗下划线**__
`行内代码`
```

`__文字__` 显示下划线；加粗使用 `**文字**`。下划线可以与加粗、斜体、高亮或链接组合。

光标靠近这些文字时可直接修改两侧标记，文字保留相应样式。标记可以逐字删除，也可以用反斜杠转义为普通字符。

## 5. 引用

> 这是引用。
>
> - 引用里的列表
> - 另一个项目
>

右键“引用”为选中文字所在行添加一层引用；未选中文字时作用于光标行。“去除一层引用”按同样规则移除一层，不影响其他行。

## 8. 图片、绘图与附件

### 显示与尺寸

图片与文字可以同行：![示例图片|320](公式和代码示例.assets/attachments/示例图片.svg)，这是图片后的文字。

![示例绘图|50%](公式和代码示例.assets/attachments/示例绘图.excalidraw)

```markdown {id=0006}
![图片说明|320](attachments/图片.png)
![图片说明|50%](attachments/图片.png)
![绘图|320](attachments/绘图.excalidraw)
```

`|320` 表示宽度 320 像素，`|50%` 表示原始尺寸的 50%，高度按比例计算。修改尺寸会立即更新预览。没有尺寸时使用默认大小。

图片平时显示预览。点击或将光标移入链接区域时，显示原始链接并隐藏预览；离开后恢复。拖选经过图片时保留预览并显示选中边框，松开鼠标后再显示链接。右键预览不会切换到源码。

### 插入与管理

可粘贴剪贴板图片，或在右侧“附件”中添加文件。新附件放入当前文档的 `.assets/attachments/` 目录；也可以链接其他目录已有的附件。

本地附件的右键菜单可查看、重命名或删除。重命名更新知识库中引用它的文档；删除附件会同时移除当前链接。

### Excalidraw

在文档要插入的位置右键 → 插入空白 Excalidraw 绘图，或从 `/` 菜单插入。绘图不插入代码块或行内代码。打开画布后可在顶部命名文件，按 Enter 保存名称。

右键绘图预览或原始链接 → 编辑绘图。绘图保存为 `.excalidraw` 文件，预览直接读取此文件；“复制链接”可在其他笔记引用同一张图。导出文档时使用矢量预览。

画布里的“字体管理”可添加本机字体。移除自定义字体后，使用它的文字改为 Excalifont；素材库会保存，下次打开可继续使用。

## 12. 文档、标签页与目录

### 打开与关闭

文件浏览器单击临时打开，标签名显示为斜体；双击或编辑后保留标签。新标签位于当前标签之后，关闭后优先回到左侧相邻标签。编辑区左上角的叉号与标签页叉号作用相同。

标签页右键可关闭其他、左侧或右侧标签。左侧工具栏提供文件、搜索、收藏、文档历史、WebDAV 和绘图入口；文件页顶部的知识库名称打开导航弹窗。移除导航记录不会删除磁盘目录，缺失的知识库显示为灰色。

### 排序与移动

文件浏览器支持拖动移动及剪切、复制、粘贴。排序菜单可按文件名、类型、修改日期和创建日期组合排序；点击排序项切换升降序，拖动排序项调整优先级。文件和文件夹一起参与排序。

顶部图标可显示或隐藏附属目录与 `.data`，也可切换为当前文档的附属目录视图。左右分隔条可拖动调整宽度；右侧文档信息包含“大纲”“附件”“数据”。

### 文档附属目录

`笔记.md` 的附属目录为同级 `笔记.assets`，内部使用 `attachments` 和 `code-data` 分类。首次产生文件时创建；移动、重命名、复制文档时同步处理目录和内部链接。

删除文档时，如果附件仍被其他文档引用，会列出受影响文档，可先移交附件再删除，或直接删除。外部操作造成孤立附属目录时，启动检查会提示重新关联或删除。

附件引用记录保存在知识库的 `.data/attachment_map.json`；应用生成的配置、映射和运行文件可在“偏好设置 → 数据与运行环境”查看。

## 13. 保存、同步与导出

### 本地保存

“偏好设置 → 编辑”提供手动保存、离开文档时保存、实时自动保存三种方式。离开文档包括切换标签页、关闭及退出；实时保存默认停止输入 900 毫秒后执行，延迟可调整，离开时立即保存。Ctrl + S / Command + S 随时保存，底部状态栏显示本地保存状态。手动模式关闭未保存文档时会询问处理方式。

文件被其他程序修改时，冲突对话框高亮差异，可选择磁盘版本或当前内容。

### WebDAV

在“偏好设置 → WebDAV”填写地址、远端目录和凭据，设置会自动应用，点击“测试连接”检查连接。在左侧 WebDAV 面板点击“立即同步”，首次同步会展示更改清单。“同步记录”显示传输操作、文件大小和耗时；“云端目录”复用扫描结果，也可手动刷新，不会自动轮询。

默认手动同步，也可以在设置中开启打开知识库后同步、保存后同步或定时同步。自动同步只处理已保存的文件；正在扫描或传输时可以取消。

删除默认先确认，也可以选择同步删除或不同步删除。排除规则支持 *、** 和 ?；代码数据可以单独排除。文件浏览器显示同步状态，面板列出冲突、同步记录和跳过的文件。冲突可以保留本地、保留远端或保留两份。

笔记及附属目录中的附件、目录记录一起同步。本机设置、运行环境、缓存和 .data 中的索引不上传；附件关联会在下载后重建。

### 附件管理

“文档信息 → 附件”列出当前文档的附件，定位按钮可跳到对应链接；文件丢失后列入“不存在的附件”。在应用内重命名或移动附件会更新相关文档的链接。右键删除附件时删除当前链接，其他引用保留；从附件面板删除文件则保留文档中的链接。

### 导出与文件查看

编辑区右侧“更多文档操作”可导出 Markdown、HTML 或 PDF。HTML / PDF 使用阅读样式，图表保留矢量，长表格和代码按页面排版。

文件浏览器还可打开文本代码文件、常见图片、PDF 和 SQLite。代码文本可编辑；PDF 可翻页、缩放和选择文字；SQLite 提供只读查询。

## 14. 字体与排版

“偏好设置 → 字体与排版”可分别设置界面、正文、代码、源码、阅读与标题的字体和字号。字体选择器可筛选本机字体；未单独设置的区域继承默认值，页面中显示当前继承关系。

标题大小使用相对正文的比例。“界面”设置可选择配色、深浅色、强调色、宽屏写作及是否显示扩展名；自定义字体和排版不会改变 Markdown 内容。

## 文档历史

左侧工具栏的“文档历史”显示当前文档的保存版本。首次修改保存时保留修改前与保存后的内容，此后默认至少间隔 2 分钟记录一次。点击版本查看差异，删除和新增内容分别高亮；“恢复此版本”回到选中的内容，恢复前的当前内容也会保留。

恢复后的内容按当前保存方式处理，手动保存模式下仍需保存。历史只记录文档文本，不回退附件或代码数据。记录存放在知识库的 .data/文档历史，默认最多保留最近 30 天内的 50 个版本；每个文档的记录文件最多 4 MB，支持 2 MB 以内的文本。可在“数据与运行环境”中清理。应用内重命名和移动保留历史，复制的文档单独记录历史。

在“偏好设置 → 编辑 → 文档历史”中，可开关历史记录，并调整记录间隔、每篇文档的版本数上限和保留天数。调整保留上限后，列表按新设置显示；下次记录时清理超出的版本。关闭历史记录仍可查看和恢复已有版本。
