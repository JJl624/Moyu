# 附件预览

图片、Excalidraw、PDF 和乐谱在独立段落中统一预览；PDF 和乐谱目前只在 Windows 启用。

附件引用单独占一个段落时显示预览。列表和引用中的独立段落也适用。与文字放在同一段落时保持链接：

```markdown
参考 [资料](资料.pdf)，这里继续写说明。

[资料](资料.pdf)

[乐谱](练习.alphatex)
```

单击图片选中，双击在文档内查看大图、缩放、旋转和切换；点击下方名称或右键“编辑引用”可修改链接。名称隐藏时，鼠标移入附件后显示。按住 Ctrl 点击链接或通过右键菜单打开附件。PDF 可在正文中翻页、缩放、搜索和选取文字，并记住页码、显示方式和缩放。

通过正文的“插入 → 乐谱”或 `/乐谱` 新建 alphaTex 乐谱。乐谱文件提供互斥的源码与预览页面，保存方式沿用应用设置。Guitar Pro、MusicXML 和 MXL 文件可导入显示，Guitar Pro 与 MXL 为只读。

alphaTex 示例：

```text
\title "练习"
\tempo 100
.
:4 0.6 2.6 3.6 0.5 | 2.5 3.5 0.4 2.4 |
```

附件的显示选项和视窗高度随文档同步；预览和翻页不修改笔记正文；源码编辑、替换引用等操作才会产生待保存内容。
