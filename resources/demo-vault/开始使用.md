# 开始使用

在左侧打开文档，直接编辑。内容保存为普通 Markdown 文件。

## 编辑

输入 `/` 插入代码块、表格或绘图。选中文字可修改格式；右上角切换源码。常驻格式工具栏默认关闭，需要时点击「文本格式」图标。

打开 [列表与块](./列表与块.md)，试试让标题、代码块和表格随整个列表项一起缩进。

| 你想做的事 | 快捷键 |
| --- | --- |
| 新建文档 | Ctrl / ⌘ + N |
| 保存 | Ctrl / ⌘ + S |
| 切换源码 | Ctrl / ⌘ + E |
| 搜索工作空间 | Ctrl / ⌘ + Shift + F |

## 文件

点击左侧工作空间名称打开知识库导航弹窗。右键文件或文件夹，可以新建、重命名或移至回收站。导入、导出在文档「更多」菜单中。

默认实时保存，可在偏好设置 → 编辑改为手动保存或关闭时保存，状态栏显示当前方式和写入结果。手动关闭未保存文档时会询问保存、放弃或取消。外部修改发生冲突时，可比较并选择要保留的内容。

## 同步、版本与绘图

左侧云图标打开 WebDAV，配置自己的服务后测试连接并同步。出现冲突时选择要保留的版本，替换前会保留恢复副本。

Git 默认关闭。在偏好设置 → 文件与附件开启后，分支图标打开版本管理：填写作者姓名与邮箱，初始化仓库，暂存后提交。远端支持 HTTPS / HTTP，可拉取、推送或克隆到空文件夹。Git 不影响本地保存与 WebDAV。

画笔图标打开 Excalidraw。在空白段落右键 → 插入空白 Excalidraw 绘图，使用标准链接，如 `![绘图|640](attachments/绘图.excalidraw)`。预览直接渲染 SVG，绘图页面可以复制链接或主动导出文件。字体管理可把本机字体加入绘图字体列表。

左下角设置可分别调整正文、标题、代码与界面的字体，以及字号、行高、间距、文档宽度、主题和格式栏开关。

右上角「文档信息」打开大纲、附件、数据页，仅显示当前文档的内容。图片使用内置查看器；附件右键可重命名并更新知识库内的标准 Markdown 引用。偏好设置 → 文件与附件选择新附件存放目录。

预览编辑与阅读模式可在代码块右上角运行代码。运行结果只存在已打开文档的 UI 内存；叉号关闭结果，关闭文档或应用、修改代码后清除，不写入文件。源码模式只显示 Markdown。

列表内代码末行按 ↓ 或 Ctrl / ⌘ + Enter 退出到当前项内空行；空行再回车创建同级项，之后每次回车减少一级缩进，直到退出列表。表格右键可选中或删除整张表格。

偏好设置 → Python 可以安装、选择和卸载 Runtime 与包，手动刷新离线目录，并配置镜像。目录不会自动联网更新。使用 display(...) 显示表格或图片；写入 /output/ 的文件会出现在运行结果中，这些文件同时写入本代码块的数据目录，结果框仍是临时界面。纯文字输出不建立数据目录。Python 相对路径从 /data 开始；await download(url, 文件名) 下载输入数据。JS/TS 使用 await files.readFile / writeFile / download。

代码块右键菜单可格式化，dprint 样式在偏好设置 → 编辑配置。Python 代码块复用同一个隔离环境，包可以复用，每次执行的变量和模型独立；需要清空时，在偏好设置 → Python 重启运行环境。

拖动代码块底部调整高度，Markdown 围栏中记录 {height=160} 一类属性；双击底部恢复不限高度。

## 标签代码块

点击标签切换代码，+ 新建，⋯ 修改标题、语言或顺序。右上角可切换源码显示。标签代码块不执行代码。

```tabs {height=180}
:::python Python 示例
print("Hello")
:::js JavaScript 示例
console.log("Hello");
:::cpp C++ 示例
std::cout << "Hello";
```

使用 `tabs` 围栏，每个标签以 `:::语言 标题` 开始，语言和标题可省略。输入 `:::` 后编辑语言；Python、JS、TS、C、C++ 标签可右键格式化。`height` 控制整块高度。

更多语法见 [Markdown 语法指南](./指南/Markdown%20语法指南.md)。Android / iOS 客户端与通用插件系统尚未提供。
