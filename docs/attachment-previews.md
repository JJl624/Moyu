# 附件预览与第三方适配

## 边界

- `shared/attachment-previews.mjs` 是类型与段落条件的唯一判断入口。图片、Excalidraw、PDF、乐谱仅在完整独立段落中预览，列表与引用里的段落同样适用；PDF 和乐谱初期只在 Windows 启用。标题、混排和软换行不是独立段落。非预览引用显示名称链接，光标进入时显示完整 Markdown。
- 本地普通附件链接可按后缀识别图片；远程普通链接和文内锚点保留链接行为。远程图片仍通过 Markdown 图片语法显示。
- `src/attachments/previewRegistry.ts` 按类型调用预览器，负责取消、销毁、加载失败回退和尺寸通知。预览器不能写正文、触发正文保存、获取正文焦点或修改列表结构；显示偏好只通过 `viewState.ts` 与文档记录接口持久化。
- 正文编辑沿用 `docs/editor-contracts.md` 的选区、拖选、历史与保存约定。预览与引用的显示切换不改变 Markdown，不算文档编辑。
- 预览铺满段落并居中，跨正文拖选保留预览与高亮；单个正文光标不得留在预览或不可编辑占位里。单击图片或绘图只选中，双击打开文档内图片查看器；点击下方名称或右键“编辑引用”进入源码。预览本体与附件段落的留白不展开源码；真实相邻空段落继续正常放置光标。键盘导航、历史恢复和上下文“编辑引用”仍沿用模型选区显示源码，不能另存一份编辑状态。
- 文档信息里的附件定位通过现有文档导航队列等候当前模式就绪；富文本由 `resourceSelection.ts` 选择整个引用并保持预览，不能借用名称编辑的内部光标。阅读模式定位使用预览选中样式，源码模式保留源码定位，不获取编辑焦点。
- 预览下方保留 26px 名称条，名称使用单行截断；空 alt 回退显示附件文件名。编辑模式名称为可点击、可键盘操作的按钮，进入引用源码时光标落在方括号内名称的起点（空名称同样适用），不在预览里直接编辑文字；阅读模式保留普通文字。名称不进入正文复制内容。全局隐藏名称仅改变可见性，悬停附件或键盘聚焦图片时重新显示，不改变占位、正文和保存状态。预览控件仍独立处理输入，不激活引用编辑。
- 图片和绘图的正文选中、拖选、右键目标框统一使用预览主体内的实际 img/SVG 外框，不包含整行占位或名称条。菜单关闭时移除目标框；原有正文选区若仍存在，继续显示其选中框。
- PDF 内嵌与文件页使用同一 EmbedPDF 阅读器，提供翻页、文本选择、搜索、缩放和密码处理。控件与内部文本选择归阅读器，正文拖选归编辑器，两者不能互相抢焦点。
- `pdfReaderPolicy.ts` 集中定义只读功能与菜单规则；界面和命令禁用列表必须一致，不允许 UI 配置覆盖全局列表重新显示无效操作。关闭/打开附件由墨屿管理，预览不提供编辑、加密或全屏；内嵌阅读器另去除打印、下载、截图与空文档菜单，独立文件页保留打印和下载。菜单过滤后去除空分组和多余分隔线，使用上游公开 UI schema。2.15.1 的数值默认缩放会保留初始化 gate；先完成自动布局，再通过公开缩放 API 恢复百分比，不能直接把已存数值当默认配置。
- Ctrl/Cmd + 滚轮仅在 PDF 容器里处理，每个非零滚轮事件以公开缩放 API 加减 0.05，避免上游连续手势再执行一次；普通滚动、触摸手势和应用其他区域保持原行为。监听器随阅读器销毁释放，不修改文档或保存状态。
- PDF 的当前页随附件视图保存，独立文件页使用既有本机页码记录。翻页命令立即记录目标，暂时保持该目标至下一次用户操作；普通滚动记录当前页。初始化等待 SDK 解除缩放 gate 后恢复页码，未操作时仅按布局/页码事件校正首屏，用户操作立即取消排队中的恢复，不用轮询或持续动画。忽略的布局事件不得推进已记录页码；双页及横排同时可见多页时仍保留用户选择。关闭时排空既有视图队列，恢复与同步回放不产生回声写入。
- 第三方阅读器的复制沿用浏览器剪贴板 API。Electron 仅向当前主窗口的可信主界面授予 `clipboard-sanitized-write`；附件/HTML 子框架与剪贴板读取不获授权。`ui-permissions.cjs` 集中判断请求来源，不修改阅读器依赖或全局替换剪贴板对象。
- 附件视图设置按知识库、文档及引用路径区分，统一写入现有 `<文档名>.assets/document.json` 的 `attachmentViews`，随文档记录同步。包括 PDF 页码、缩放模式、分页、方向、拖动及侧栏，乐谱缩放、布局、音轨、播放选项和暂停位置，图片查看器缩放、旋转，以及 PDF/乐谱视窗高度。只读打开、恢复、响应式重排和相同选项不写入；实际操作合并延迟写入，关闭、复制、重命名和手动同步前排空队列。首次实际修改只创建文档记录，不创建空附件或代码目录，不修改 Markdown、不创建正文历史。重命名和复制必须更新引用键并保留其他记录字段。独立 PDF 文件页继续使用有界的本地页码设置作为回退。
- 乐谱提供缩放、分页/横向布局、音轨选择、播放/暂停、停止、速度、循环与节拍器。首次播放才加载本地音源并启用播放器，同一时间只播放一份乐谱。内容可滚动、视窗可调整并记住高度，不裁掉长谱或宽谱。
- alphaTab 使用官方默认 AudioWorklet，避免旧 ScriptProcessor 依赖界面线程供音。当前 1.8.4 有异步启动/停止竞态，独立 `scripts/alphatab-audio-adapter.mjs` 在构建副本中以音源身份取消旧启动，禁止停止尚未 start 的音源。构建同时校验版本与转换锚点；不修改 node_modules。发布包保留修改后的可读 core 与适配源码，升级时核对上游修复后移除。
- 音轨选择以 `api.tracks` 为准，在 renderStarted 时同步 UI；初次明确渲染全部音轨，不能把“全部”下拉选项当作引擎已渲染全部。播放进度、总时长、定位、音量与游标使用公开播放器事件/API，不通过改乐谱或正文实现。
- `scoreToolbar.ts` 只负责显示与控件生命周期，`scoreControls.ts` 负责播放器状态。播放、音轨、进度、缩放和布局合并为上方一行；音轨有明确的紧凑宽度，窄预览把缩放和布局移入菜单，保留同一组控件和状态。音量、速度、停止、循环和节拍器使用工具栏的原生 popover，避免窄预览裁切，支持 Escape、点击外部和键盘焦点返回。内嵌视窗仅在全部初始音轨首次排版完成后按内容收拢，后续缩放、播放或排版不覆盖手动高度；独立文件页保留全页视窗。菜单与视图操作不得写入正文。
- 所有预览控件、名称和显示尺寸只改变显示，不修改 Markdown 引用或附件内容；视图偏好通过上条的文档记录保存，视窗变化通过注册表通知几何层。只有在引用源码里修改名称或尺寸才算文档编辑。
- alphaTex 文本可在乐谱文件页切换源码/预览，沿用普通文本保存和冲突流程。Guitar Pro/MXL 导入显示只读；alphaTab 不是图形化制谱编辑器。
- 文档内图片查看器仅包含当前文档的普通图片及 Excalidraw，按正文顺序导航；方向键切换，Escape 关闭，Ctrl/Cmd + 滚轮缩放，支持旋转及拖动平移。查看器可拖动右下角改变宽高，双击手柄恢复默认；宽高以 `attachmentViews["moyu-view:image-window"]` 按文档保存并同步，不依赖当前图片。窗口及图片都按可用空间约束。复用已有图像/SVG，切换或关闭释放对象 URL；返回时保持正文选区和位置，不借用引用编辑状态。
- PDF/乐谱使用悬停附件时显示的高度拖动条，保留固定占位，键盘聚焦及正在拖动时可见，不因显隐造成重排；不保留浏览器原生 resize 写下的固定宽度；乐谱渲染以实际可用内容宽度重新排版。默认分页在窗口反复缩放后不得留下虚假横向滚动条，横向谱及主动放大产生的滚动保留。
- 附件与正文使用浏览器默认滚动及滚动链；附件内部能滚动时优先滚动附件，到边界或无内部滚动空间时由浏览器交给正文。不得为普通滚轮阻止默认事件、手动写正文位置或增加交接动画；保留乐谱视窗的 `overscroll-behavior:auto`。PDF 的 Ctrl/Cmd 缩放是独立功能，仍按 5% 调整。浮动图片查看器是独立对话框，其缩放画布不滚动背后的正文。
- 新预览按可见范围加载。销毁或替换时取消旧请求，释放 Worker、对象 URL、观察器和事件；异步旧结果不得修改新文档。
- 拖入附件先由 `DocumentMap` 确定附属目录，再由 `Attachments` 写入并为同名文件编号。外部复制笔记及其相邻 `.assets` 后，首次添加附件可更新仍记录旧路径的归属；必须有合法记录、完整文件名相同，且目录未被其他文档占用。缺失记录、不同文件名或既有归属冲突必须拒绝，不能覆盖原文件。目录错误保留具体原因，不得统一伪装为附件重名。

## 第三方升级

依赖使用精确版本。不得修改 node_modules 或直接在界面组件中引用第三方内部结构。

| 工具 | 版本 | 适配位置 |
| --- | --- | --- |
| Excalidraw | 0.18.1 | `scripts/excalidraw-adapter.ts`、`excalidraw-wasm.ts`、`excalidraw-csp.ts` |
| EmbedPDF | 2.15.1 | `src/attachments/pdfAdapter.ts`、`pdfReaderPolicy.ts` |
| alphaTab | 1.8.4 | `src/attachments/scoreAdapter.ts`、`scoreControls.ts` |
| MathLive | 0.111.1 | `src/FormulaAssistant.tsx`、`src/editor/formulaEditing.ts`、`sourceFormulaEditing.ts` |

Excalidraw 目前有版本绑定的构建转换：本地中文与字体、去除远端字体回退、字体格式/名称兼容、CSP 字体处理、素材库导入与字体注册、透明度数值输入。版本不符或已知转换锚点缺失时构建失败，禁止直接升级后发布。

EmbedPDF、MathLive 使用上游发行文件及公开 API；alphaTab 只有上述隔离的音频生命周期适配。`scripts/prepare-preview-assets.mjs` 从固定 npm 包准备本地 Worker、Wasm、字体与 Sonivox 音源及其许可；运行时不依赖 CDN。MathLive 按需加载，关闭按键音，不引入 Compute Engine。EmbedPDF 的紧凑工具栏只通过公开 UI schema 调整，升级时核对其工具栏及项目 ID。PDF 旧 PDF.js 引擎已移除。

升级流程：检查公开 API 和发行说明 → 更新版本及必要适配 → 离线资源与许可证核验 → 附件结构/保存/销毁回归 → Windows 包内验证。只有这些步骤通过才更新本表。
